# Logistics Freight Hero

"Logistics that works as hard as you do." — an animated full-viewport hero over an aerial freight-train photograph.

## Structure

- `public/index.html` — deployable page
- `public/assets/images/` — background photograph
- `public/assets/fonts/` — subset WOFF2 faces
- `wrangler.jsonc` — Cloudflare Pages configuration

## Local preview

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```
